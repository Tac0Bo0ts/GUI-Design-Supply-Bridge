# SupplyBridge App

## Description:
This project is a Python and Kivy application used to manage inventory items, record donations, handle requests, and log distributions. It uses an in-memory backend and a mobile-style interface. The purpose is to keep a log of all school supplies that the company handles.

## How to Install:
Install Python


## Install Kivy:
pip install kivy

## How to Run It:
Run the main application file:
python gui_application_kivy.py
